Now in this module first we will learn how data is transmitted across the internet using packet-based communication, and how standard protocols ensure data reaches the correct destination reliably and efficiently.

## Packet-Based Communication

- Digital data is broken into **small units called packets**.
- Each packet contains:
  - A portion of the original data
  - Source and destination addressing information
- Packets may travel **different paths** across the network.
- Packets are **reassembled** in the correct order at the destination.

## Why Packets Are Used

- Sending data in packets:
  - Improves efficiency
  - Allows multiple devices to share the network
  - Prevents a single failure from stopping all communication
- If a packet is lost, **only that packet** needs to be resent.

## Reliability and Sequencing

- Packets include **sequence numbers**.
- Sequence numbers allow the receiving device to:
  - Reorder packets correctly
  - Detect missing packets
- Missing packets can be **requested again**.

## Core Protocols and Their Roles

### IP (Internet Protocol)

- Responsible for:
  - Addressing packets
  - Routing packets across networks
- IP does **not** guarantee delivery.

### TCP (Transmission Control Protocol)

- Provides **reliable communication**.
- Ensures:
  - Packets arrive in order
  - Lost packets are retransmitted
  - Duplicate packets are handled correctly
- Commonly used for:
  - Web pages
  - Email
  - File transfers

### UDP (User Datagram Protocol)

- Provides **fast, connectionless communication**.
- Does not guarantee:
  - Delivery
  - Order
- Commonly used for:
  - Video streaming
  - Online gaming
  - Voice communication

## Application-Level Protocols

- **DNS**
  - Converts domain names into IP addresses.
- **HTTP**
  - Defines how web data is requested and delivered.
- **HTTPS**
  - Encrypts HTTP traffic for security.

## Layered Communication Model

- Network communication is divided into **layers**.
- Each layer has a specific responsibility.
- Layers allow:
  - Easier troubleshooting
  - Independent development of technologies
  - Interoperability between different vendors and systems

## Network Structure

- The internet is a **decentralized system**.
- There is no single controlling device or path.
- Routing decisions are made dynamically as packets travel.

## Key Takeaway

The internet relies on packet-based transmission and layered protocols to move data reliably, efficiently, and securely across a global, decentralized network.
