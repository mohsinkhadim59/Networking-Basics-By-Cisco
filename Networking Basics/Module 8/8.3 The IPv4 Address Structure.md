## IP Addressing in a Multi-Network Environment 
### 1. IP Across Multiple Networks
- Earlier, all devices you worked with were on **one local network**.
- In real environments, companies often have **multiple networks** (departments, floors, buildings).

### 2. How IP Knows a Device Is on a Different Network
- Every IPv4 address has **two parts**:
  - **Network portion**
  - **Host portion**
- Devices are grouped by the **network portion** of their IP address.

### 3. Example: Three Department Networks
- **Network Management Department:** `192.168.1.x`  
- **Accounting Department:** `192.168.2.x`  
- **Sales Department:** `192.168.3.x`

All devices within the same department must share the **same network portion** (first three octets in this example) but have a **unique host portion** (last octet).

### 4. Same Network = Same Network Portion
- In the Sales Department:  
  - Network portion = `192.168.3`  
  - Example device IP = `192.168.3.10`
  - No other device in Sales can also use `.10`—the host portion must be unique.

### 5. Different Network = Different Network Portion
- Accounting: `192.168.2.x`  
- Network Management: `192.168.1.x`  
- Each network uses a different **third octet** to separate them.

### 6. What Happens If a Device Has the Wrong Network Portion?
- If you move a computer from one network to another **without changing its IP**, it will not communicate.
  - Example: A device with `192.168.3.10` moved to the `192.168.1.x` network will fail to connect.
- Why?  
  Because its IP address no longer matches the local network’s assigned network portion.

### 7. Basic Rule of IP Networks
- **All devices on the same LAN must have the same network portion.**
- **Every device must have a unique host portion.**

---

>[!example] 
>- **Office scenario:**  
  >A computer from the Sales floor is moved to Accounting. If its IP stays `192.168.3.10`, it won’t print, access servers, or connect to others in Accounting until the IP is updated to `192.168.2.x`.
>
>- **Home network:**  
  >Your laptop (`192.168.0.15`) and your smart TV (`192.168.0.22`) communicate because they share the same network portion (`192.168.0`).  
  Your neighbor’s Wi-Fi uses a different network portion (`192.168.1.x`), so your devices can’t talk to theirs.

## Summary: Networks and Hosts in IPv4 Addressing (with Real-Life Examples)

### 1. IPv4 Addresses Are Hierarchical
- An IPv4 address (32 bits) has **two parts**:
  - **Network portion** (identifies the network)
  - **Host portion** (identifies the specific device on that network)
- These two parts are determined using the **subnet mask**.

>[!example]
>- IP address: **192.168.5.11**  
>- Subnet mask: **255.255.255.0**
>- Network portion = **192.168.5**  
>- Host portion = **11**

This means “Network 192.168.5” contains a host with ID “11”.

### 3. Hierarchical Addressing
- Hierarchical Addressing: **Network portion indicates the network on which each unique host address is located.**
	- Because the address is hierarchical, **routers only need to know how to reach networks**, not individual hosts
	- This makes routing much faster and more efficient.

### 4. Multiple Logical Networks on One Physical Network
- Physical network = the actual wires, Wi-Fi, switches, etc.
- Logical network = defined by the IP network portion.

>[!Example]  
On the same physical LAN:
>- Devices with **192.168.18.x** can talk to each other.
>- Devices with **192.168.5.x** can talk to each other.
>- But **192.168.18.x cannot talk to 192.168.5.x** unless a router is used.
>![Example](/Imagesn/72.png)
>*Figure: Two Logical Networks on One Physical Network*
>This creates:
>- **1 physical network**
>- **2 logical IPv4 networks**

### 5.  Analogy: Telephone System
- A phone number is also hierarchical:
  - **Country code → network**
  - **Area code → sub-network**
  - **Exchange + local number → specific phone**
- Just like IP address parts, the first sections tell the system where to route the call.

### 6. Another Example
For a host with:
- IP: **192.168.18.57**
- Mask: **255.255.255.0**

The parts are:
- Network portion: **192.168.18**
- Host portion: **57**
