## How a Router Forwards Packets Between Networks

### Host Sending to a Remote Network
- **H1 (10.0.0.1)** wants to send a packet to **H4 (192.168.1.2)**, which is on a **different network**.  
- The packet contains:
  - **Source IP:** 10.0.0.1  
  - **Destination IP:** 192.168.1.2
- **H1 sends the packet to its default gateway (the router)** because the destination is not on its local network.

![Router Forwarding Example](/Imagesn/117.png)
<p align="center"><em>Figure 1: Host Sends Packet to Router</em></p>

---

## Router Processing the Packet
- The router receives the frame and examines the **destination IP address**.
- It checks its **routing table**.
- It sees that **192.168.1.2 belongs to the 192.168.1.0 network**, which is reachable through its **FastEthernet0/2** interface.
- The router then **forwards the packet out FastEthernet0/2** toward the final destination.

![Routing Table Lookup](/Imagesn/118.png)
<p align="center"><em>Figure 2: Router Checks Routing Table</em></p>

---

## What Happens With Broadcast Traffic
- H1 sends a packet to **255.255.255.255** (the IPv4 broadcast address).
- Broadcasts are meant for **all devices on the same local network**.

![Broadcast Packet](Imagesn/119.png)
<p align="center"><em>Figure 3: Broadcast Packet</em></p>

- The router **receives** the broadcast but **does NOT forward** it to other networks.
- Broadcasts stay **within the same broadcast domain**.

![Router Blocking Broadcast](Imagesn/120.png)
<p align="center"><em>Figure 4: Router Blocks Broadcast</em></p>

# Packet Delivery to a Remote Network
Let us understand via an example that how packet is delivered to remote network because so far we have learned that with in a network a packet can be delivered easily via **ARP and CAM** of the **End Device and Switch** respectively. 
###  H1 → H3 through a Router

- **H1:** `192.168.1.10`, MAC `AA-AA`
    
- **Router R1:**
    
    - Interface F0/1 → Network 192.168.1.0, IP `192.168.1.1`, MAC `11-11`
        
    - Interface F0/2 → Network 192.168.2.0, IP `192.168.2.1`, MAC `22-22`
        
- **H3:** `192.168.2.50`, MAC `CC-CC`

```

# 2. Stepwise Details

## Step 1: H1 builds the IPv4 packet

| Field          | Value        |
| -------------- | ------------ |
| Source IP      | 192.168.1.10 |
| Destination IP | 192.168.2.50 |

H1 checks the subnet mask → destination is **not local** → must send to **default gateway (192.168.1.1)**.

---

## Step 2: H1 prepares the Ethernet frame (Layer 2)

Since H3 is on a **different network**, H1 must send the frame to the **router's MAC**.

| Field              | Value               |
| ------------------ | ------------------- |
| L2 Source MAC      | AA-AA               |
| L2 Destination MAC | 11-11 (router F0/1) |

H1 gets this MAC via ARP (or already cached).

### Visual: Frame from H1 → Router

```
[IPv4 Packet: 192.168.1.10 → 192.168.2.50]
Encapsulated in:
Ethernet Frame:
    Src MAC = AA-AA
    Dst MAC = 11-11
```

---

## Step 3: Router Processes the Packet

###  Router receives the frame

- Destination MAC matches its interface (11-11)
    
- Router strips the **Ethernet header**
    
- Still has:  
> IPv4 packet: src 192.168.1.10, dst 192.168.2.50```
    

###  Layer 3 routing decision

Router checks routing table:

| Destination Network | Exit Interface |
| ------------------- | -------------- |
| 192.168.2.0/24      | F0/2           |

So router forwards packet out **F0/2**.

---

## Step 4: Router builds a _new_ Ethernet frame

Before sending to H3, router needs H3’s MAC (`CC-CC`) via ARP (or cached).

| Field              | Value               |
| ------------------ | ------------------- |
| L2 Source MAC      | 22-22 (router F0/2) |
| L2 Destination MAC | CC-CC (H3)          |

### Visual: Frame from Router → H3

```
[IPv4 Packet: 192.168.1.10 → 192.168.2.50]
Encapsulated in NEW Frame:
    Src MAC = 22-22
    Dst MAC = CC-CC
```

---

## Step 5: H3 receives the packet

- H3 sees MAC = CC-CC → frame is for it
    
- Removes Layer-2 header
    
- Checks IPv4 destination = 192.168.2.50 → matches
    
- Packet delivered successfully.
    

---

# 7. Summary of Steps

```
Step 1: H1 checks subnet → remote → use gateway
Step 2: H1 encapsulates packet → frame with dst MAC = 11-11
Step 3: Router receives → strips L2 → looks up route
Step 4: Router encapsulates with new frame (22-22 → CC-CC)
Step 5: H3 receives Ethernet frame → extracts IPv4 packet
```

| Stage   | Source MAC | Destination MAC | Source IP    | Destination IP | Notes                           |
| ------- | ---------- | --------------- | ------------ | -------------- | ------------------------------- |
| H1 → R1 | AA-AA      | 11-11           | 192.168.1.10 | 192.168.2.50   | H1 sends to gateway             |
| R1 → H3 | 22-22      | CC-CC           | 192.168.1.10 | 192.168.2.50   | Router forwards to next network |

## Routing Table Entries 

- Routers use routing tables to forward packets between local and remote networks.
- A routing table stores network addresses (not individual hosts) and the best path to reach those networks.

- Routing table entries can be added in two ways:
	- **Dynamic routes** – learned automatically from other routers.
	- **Static routes** – manually configured by an administrator.
![Routing Table](/Imagesn/121.png)
<p align="center"><em>Figure 5: Routing Table Entries</em></p>

When a router receives a packet, it checks the routing table to determine which interface to use to forward it.

- If no matching route exists, the router will drop the packet. To avoid this, routers use a **default route**, which is used when the destination network is unknown.  
The default route usually points to another router that can forward the packet toward its final destination.

___
## The Default Gateway

- Sending messages differs depending on whether the destination is on the same network or a remote network.

### Same Local Network
- The host forwards the message directly.
- Uses **ARP** to discover the MAC address of the destination host.
- The IPv4 packet is encapsulated in a frame with the destination host's MAC address.

### Remote Network
- The host must use a **router**.
- The IPv4 packet still contains the destination IP address.
- The frame uses the **MAC address of the router** as the destination.
- The router receives and forwards the packet toward the remote host.

### Determining the Router's MAC Address
- Each host has a **default gateway** configured in its TCP/IP settings.
- The default gateway is the IPv4 address of the router interface on the local network.
- The host uses ARP to find the MAC address of the router and places it in the frame.
![Default Gateway](/Imagesn/122.png)
<p align="center"><em>Figure 6: Default Gateway Configuration</em></p>

 >[!Notes]
>- Correct configuration of the default gateway is crucial.
>- If the default gateway is missing or incorrect, messages to remote networks cannot be delivered.
