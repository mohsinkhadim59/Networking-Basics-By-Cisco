## Why Large Networks Are Divided into Smaller Networks

### 1. Reduce Broadcast Traffic
- In a single large LAN, every broadcast is received and processed by all devices.
- Most broadcasts are not useful to every device, so dividing the network reduces unnecessary processing.
- Smaller networks create smaller broadcast domains.

### 2. Improve Security
- Different departments may need restricted access to each other's devices.
- Dividing the network prevents users in one department from seeing or accessing devices in another.

### 3. Geographic Separation
- Departments may move to different floors or buildings where a single LAN cannot physically reach.
- Creating smaller network segments supports expansion or relocation.

---

## How Networks Are Divided

### Routers
- Routers separate networks.
- Each router interface becomes a separate network and a separate broadcast domain.
- Router interfaces also define separate IP networks with different IP address ranges.

### Effect of Adding Routers
- One large network becomes multiple smaller networks.
- Broadcasts stay within their own segment.
- Security and network management improve.

---
## Now We Need Routing

### Connecting Beyond the Local Network
- Devices often need to reach networks outside their local segment (homes, businesses, the internet).
- Devices outside the local network are called **remote hosts**.
- When sending to a remote host, routing is required to deliver the packet across different networks.

---

## Routing-in short
- **Routing** is the process of finding the best path to a destination.
- A **router** connects multiple Layer 3 (IP) networks.
- Routers operate at the **distribution layer**, directing traffic efficiently.

---

## How Routers Make Decisions
- Switches make decisions based on **Layer 2 MAC addresses**.
- Routers make decisions based on **Layer 3 IP addresses**.
- An IP packet includes:
  - Source IP address  
  - Destination IP address  
  - Payload (the actual message)
![Router sees IP](/Imagesn/116.png)
- The router reads the **network portion** of the destination IP to determine which interface or network to forward it to.

---

## When Routing Is Required
- If the **network portions** of the source and destination IPs **do not match**, a router must forward the packet.
- Example:
  - Source: `1.1.1.0` network  
  - Destination: `5.5.5.0` network  
  - The host sends the packet to the router.

---

## What the Router Does
1. **Receives** the frame from the host.
2. **De-encapsulates** the Ethernet frame to access the IP packet.
3. **Reads** the destination IP address.
4. **Determines** the correct outgoing network/interface.
5. **Re-encapsulates** the IP packet into a new frame.
6. **Forwards** the frame toward the destination.

Routers ensure packets travel correctly between different networks and reach remote hosts.
