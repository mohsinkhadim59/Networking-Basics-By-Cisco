## Ethernet Broadcast

- An Ethernet broadcast occurs when the **destination MAC address is all 1s**.
- In hexadecimal format, this broadcast MAC address is **FF:FF:FF:FF:FF:FF**.
- A broadcast frame is sent when a device needs **all other devices on the local network to receive the message**.

### How a Broadcast Works in a Switched Network

- Host H1 sends an Ethernet frame with the broadcast MAC address.
![Broadcast](/Imagesn/107.png)
- When the switch receives a broadcast frame:
  - It **floods the frame out of all ports**
  - Except for the **port on which the frame was received**
- As a result, **every device connected to the switch receives the broadcast**.
![Broadcast](/Imagesn/108.png)
### Role of the Router in an Ethernet Broadcast

- If a router is connected to the network:
  - It **will receive the broadcast frame**
  - But it **will NOT forward the broadcast to other networks**
- This behavior **contains broadcasts within the local network only**

## Broadcast Domains

- When a host receives a message sent to the **broadcast address**, it:
  - **Accepts the message**
  - **Processes it as if it were sent directly to that host**

- When a host sends a **broadcast message**:
  - **Switches forward the message to every connected host**
  - All devices must process the broadcast

- Because of this behavior:
  - A **local area network with one or more Ethernet switches** also known as **broadcast domain**

### Effects of Large Broadcast Domains

- If **too many hosts** exist in the same broadcast domain:
  - Broadcast traffic can become **excessive**
  - Network performance **decreases**

- The number of supported hosts depends on:
  - The **capabilities of the switches**
  - The **amount of total network traffic**

- As more hosts are added:
  - Overall traffic **increases**
  - Broadcast traffic **also increases**

### Dividing Broadcast Domains

- To improve performance:
  - A single network is often **divided into multiple networks**
  - Each new network becomes its own **broadcast domain**

- **Routers are used to divide broadcast domains**
  - Routers **block broadcast traffic from passing between networks**
  - Each side of the router becomes a **separate broadcast domain**

## Access Layer Communication

| Condition | Action |
|-----------|--------|
| Frame destination MAC = broadcast MAC | NIC accepts frame |
| Frame destination MAC = NIC's own MAC | NIC accepts frame |
| Frame destination MAC = something else | NIC ignores frame |

**Problem:** Sending host knows **IP address** of destination but **not MAC**.

**Solution:** Use **ARP (IPv4)** or **Neighbor Discovery (IPv6)** to discover the MAC address of the host on the same network.

## ✅ ARP (Address Resolution Protocol)

### What is ARP?
- ARP is used when a host **knows the IPv4 address** of the destination but **does not know the MAC address**.
- It allows the host to encapsulate the IP packet in an Ethernet frame for delivery on the same local network.

### How ARP Works 

1. **Check ARP Table**  
   - The sending host (e.g., PC 1) first checks its ARP table for the MAC address corresponding to the IPv4 address (e.g., 192.168.1.9 for an FTP server).  
![ARP 1](/imagesn/111.png)
2. **Send ARP Request**  
   - If the MAC address is not in the ARP table, the host sends an **ARP request**.  
   - The ARP request is an **Ethernet broadcast** (destination MAC = all 1s) to all devices on the local network.  
![ARP 1](/imagesn/112.png)
3. **Switch Behavior**  
   - When a switch receives the broadcast, it **floods it to all ports except the incoming port**
   ![ARP 1](/imagesn/113.png)

4. **Device Response**  
   - The device with the matching IPv4 address (e.g., the FTP server) replies with its MAC address in an **ARP reply**.  
   - The reply is **unicast** directly back to the requesting host.  
![ARP 1](/imagesn/114.png)
4. **Send the Ethernet Frame**  
   - The sending host now knows the MAC address and can send the IP packet **encapsulated in an Ethernet frame** directly to the destination.

___
## ARP: Address Resolution Protocol

ARP discovers the **MAC address** of a host when only its **IPv4 address** is known.

### How ARP Works

1. **ARP Request (Broadcast)**
    - Sending host broadcasts a frame with the destination IPv4 address.
2. **ARP Reply**
    - The host with the matching IPv4 address replies with its MAC address.
3. **ARP Table** 
    - Sender stores the IPv4–MAC mapping in its **ARP table** for future use.


> [!Notes]
> ARP works only within the **same broadcast domain**. For remote networks, the **default gateway’s MAC address** is used.
