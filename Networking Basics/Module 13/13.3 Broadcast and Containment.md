## Ethernet Broadcast

- An Ethernet broadcast occurs when the **destination MAC address is all 1s**.
- In hexadecimal format, this broadcast MAC address is **FF:FF:FF:FF:FF:FF**.
- A broadcast frame is sent when a device needs **all other devices on the local network to receive the message**.

### How a Broadcast Works in a Switched Network

- Host H1 sends an Ethernet frame with the broadcast MAC address.
![Broadcast](/Imagesn/107.png)
- When the switch receives a broadcast frame:
  - It **floods the frame out of all ports**
  - Except for the **port on which the frame was received**
- As a result, **every device connected to the switch receives the broadcast**.
![Broadcast](/Imagesn/108.png)
### Role of the Router in an Ethernet Broadcast

- If a router is connected to the network:
  - It **will receive the broadcast frame**
  - But it **will NOT forward the broadcast to other networks**
- This behavior **contains broadcasts within the local network only**

## Broadcast Domains

- When a host receives a message sent to the **broadcast address**, it:
  - **Accepts the message**
  - **Processes it as if it were sent directly to that host**

- When a host sends a **broadcast message**:
  - **Switches forward the message to every connected host**
  - All devices must process the broadcast

- Because of this behavior:
  - A **local area network with one or more Ethernet switches**
  - Is also called a **broadcast domain**

### Effects of Large Broadcast Domains

- If **too many hosts** exist in the same broadcast domain:
  - Broadcast traffic can become **excessive**
  - Network performance **decreases**

- The number of supported hosts depends on:
  - The **capabilities of the switches**
  - The **amount of total network traffic**

- As more hosts are added:
  - Overall traffic **increases**
  - Broadcast traffic **also increases**

### Dividing Broadcast Domains

- To improve performance:
  - A single network is often **divided into multiple networks**
  - Each new network becomes its own **broadcast domain**

- **Routers are used to divide broadcast domains**
  - Routers **block broadcast traffic from passing between networks**
  - Each side of the router becomes a **separate broadcast domain**
