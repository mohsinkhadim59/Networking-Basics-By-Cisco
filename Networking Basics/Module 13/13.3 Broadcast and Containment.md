## Ethernet Broadcast

- An Ethernet broadcast occurs when the **destination MAC address is all 1s**.
- In hexadecimal format, this broadcast MAC address is **FF:FF:FF:FF:FF:FF**.
- A broadcast frame is sent when a device needs **all other devices on the local network to receive the message**.

### How a Broadcast Works in a Switched Network

- Host H1 sends an Ethernet frame with the broadcast MAC address.
![Broadcast](/Imagesn/107.png)
- When the switch receives a broadcast frame:
  - It **floods the frame out of all ports**
  - Except for the **port on which the frame was received**
- As a result, **every device connected to the switch receives the broadcast**.
![Broadcast](/Imagesn/108.png)
### Role of the Router in an Ethernet Broadcast

- If a router is connected to the network:
  - It **will receive the broadcast frame**
  - But it **will NOT forward the broadcast to other networks**
- This behavior **contains broadcasts within the local network only**
