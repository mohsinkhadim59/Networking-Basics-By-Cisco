# Default Gateway 

## Gateway
- A **gateway** is a hardware or a software device that allows traffic to leave one local network and reach other remote networks.
- The **default gateway** is the specific router interface that a host uses when it needs to send traffic to a destination **outside its own local network**.
- You can think of the default gateway as the **exit door** of the network. If a device wants to go anywhere beyond its own network, it must go through that door.

---

## Minimum Configuration Required on a Host
Every host must have:
- **IP address**
- **Subnet mask**

If the host needs to communicate with devices on **other networks**, it must also have:
- **Default gateway address**

Without a default gateway, a device can only communicate with devices on its own local network.

---

## How a Host Decides Where to Send Traffic
1. The host takes the **destination IP address**.
2. It applies its **subnet mask** using **binary ANDing**.
3. It compares the resulting **network portion** to its own network:
   - If they **match** → destination is **local** → send directly.
   - If they **do not match** → destination is **remote** → send to the **default gateway**.

---

## How the Host Reaches the Gateway (ARP)
Before sending traffic to the gateway, the host must know the **MAC address** of the gateway.

The host:
1. Sends an **ARP request** asking: “Who has this gateway IP?”
2. The router replies with its **MAC address**
3. The host then sends the packet to that MAC address

If the gateway IP is **wrong or on a different subnet**, ARP fails and **remote communication breaks completely**.

---

## Typical Default Gateway Setup
- The default gateway is **normally the router interface on the same subnet as the host**
- Different networks or departments use **different router interfaces**
- All hosts on the same subnet typically use **the same gateway**

---

## Network Topology 


```bash
                         Internet
                            |
                        [ Router ]
                       /          \
                 Switch A       Switch B
                 |      |      |        |
             Host A1 Host A2  Host B1 Host B2

Addressing Information
Router:

- G0/0 → 192.168.1.1 (Gateway for Network A)
    
- G0/1 → 192.168.2.1 (Gateway for Network B)
    

Network A: 192.168.1.0/24

- Host A1 → 192.168.1.10 GW: 192.168.1.1
    
- Host A2 → 192.168.1.11 GW: 192.168.1.1
    

Network B: 192.168.2.0/24

- Host B1 → 192.168.2.10 GW: 192.168.2.1
    
- Host B2 → 192.168.2.11 GW: 192.168.2.1
    
```

---

## What Happens When Host A1 Talks to Host B1

- Host A1 → 192.168.1.1 (Gateway) → Router → 192.168.2.1 → Host B1
- Host A1 sees Host B1 is **not on its local network**
- Host A1 sends traffic to **its own gateway**
- The router forwards the traffic to Network B

---

## Common Configuration Mistakes
- Setting a **gateway that is not on the same subnet**
- Using the **wrong subnet mask**
- Typing the gateway IP incorrectly

>[!Example] Example of a broken setup:
>- Host IP: `192.168.1.10/24`
>- Gateway: `192.168.2.1` ❌  
This host **cannot ARP for the gateway and cannot reach remote networks**.

---

>[!Notes]
>- The default gateway is the **router interface used to leave the local network**
>- Subnet masks determine **local vs remote**
>- Subnet masks determine **local vs remote**
>- ARP is required to reach the gateway
>- Each subnet uses a **different gateway**
>- A wrong gateway configuration **breaks all off-network communication**

# Routers as Gateways

A **router** provides a gateway through which hosts on one network can communicate with hosts on different networks.  
Each **router interface** is connected to a **separate network**.

The **IPv4 address assigned to a router interface** identifies the local network that is directly connected to it.

---

## Default Gateway

Every host on a network must use the router as a gateway to reach **other networks**.  
For this reason, each host must know the **IPv4 address of the router interface** connected to its own network.  

This address is called the **default gateway address**.

The default gateway can be:
- **Statically configured** on the host  
- **Dynamically assigned** by **DHCP**

---

## DHCP and the Default Gateway

When a **wireless router** is configured as a **DHCP server** for the local network, it automatically sends:
- The **correct IPv4 address** to the host
- The **subnet mask**
- The **default gateway address**

In the setup shown below:
![Router](/Imagesn/101.png)
<p align="center"><em>Figure 1: Router as Default Gateway</em></p>

- The router provides **its own internal IPv4 address** as the **default gateway**
- All hosts use this address to forward traffic to:
  - Other networks
  - The ISP
  - The Internet

Wireless routers are **usually configured as DHCP servers by default**.

---


>[!note] Key Concept  
The **IPv4 address of the local router interface** becomes the **default gateway address** for all hosts on that network.  
This information is provided either:
>- **Manually (static)**
>- **Automatically (DHCP)**

___
# Routers as Boundaries Between Networks

A **wireless router** acts as a **DHCP server** for all local hosts attached to it, either by:
- **Ethernet cable**
- **Wireless connection**

These local hosts are part of the **internal (inside) network**.

---

## Internal Network Addresses

Most DHCP servers assign **private IPv4 addresses** to hosts on the internal network instead of **public internet-routable addresses**.  
This ensures that, by default, the **internal network is not directly accessible from the internet**.

- The router's local interface IPv4 address is usually the **first host address** on the network.  
- Internal hosts must have addresses **in the same network** as the router.  
- Addresses can be assigned:
  - **Statically**
  - **Dynamically via DHCP**

When configured as a DHCP server, the router provides:
- **IP addresses in the internal range**
- **Subnet mask**
- **Router’s interface IPv4 address** as the **default gateway**

---

## External Network and ISP

Many ISPs also use **DHCP servers** to assign addresses to the **internet side of the router**.
![Router and External Network](/Imagesn/102.png)
<p align="center"><em>Figure 2: Router Internal and External Networks</em></p>

The network assigned to the **internet-facing interface** is called the **external (outside) network**.

- The wireless router acts as a **DHCP client** to receive the correct external IPv4 address.  
- ISPs typically provide an **internet-routable address**, enabling hosts to access the internet.

---

> [!note] Key Concept  
> The **wireless router** serves as the **boundary** between the **internal (local) network** and the **external (internet) network**.
