## DNS (Domain Name System)

- DNS maps **domain names / hostnames** to **IP addresses**
- Networks and the internet **do not understand domain names**, only IP addresses
- DNS provides the translation needed before communication can occur

### How DNS Works

1. A user enters a domain name (e.g., `www.cisco.com`)

	![Domain Name](/Imagesn/129.png)
2. The host sends a **DNS query** to a DNS server

	![DNS Query](/Imagesn/130.png)
1. The DNS server looks up the domain name
2. The DNS server returns the associated **IP address**
	![DNS Query](/Imagesn/131.png)
3. The host uses the IP address to contact the destination web server
	 ![DNS Query](/Imagesn/132.png)
4. The web server responds with the requested webpage content

## nslookup Command

- Devices must know a **DNS server address** to resolve domain names
- In home networks, DNS settings are usually provided automatically by **DHCP** on the home router
- The ISP supplies the DNS server address to the router
- The router distributes DNS information to devices using DHCP

### How Name Resolution Works

1. A user enters a domain name (e.g., `www.cisco.com`)
2. The DNS client on the device sends a request to the DNS server
3. The DNS server responds with the corresponding IP address (e.g., `172.230.155.162`)
4. The device then sends the HTTP request to that IP address

### nslookup (Windows Command Line Example)

```bash
C:\Users\User> nslookup www.cisco.com
Server:  dns.example.net
Address:  192.168.1.1

Non-authoritative answer:
Name:    www.cisco.com
Address: 172.230.155.162
```
