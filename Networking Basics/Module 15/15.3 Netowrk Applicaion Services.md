## Common Network Application Services

Common internet services (web browsing, email, streaming, messaging, online shopping) rely on **TCP/IP protocols** to enable communication between clients and servers.

![Network Application Services](/Imagesn/128.png)
### Common Network Protocols and Their Functions

| Protocol | Description |
|--------|-------------|
| **DNS (Domain Name System)** | Resolves internet domain names into IP addresses. |
| **SSH (Secure Shell)** | Provides secure remote access to servers and networking devices. |
| **SMTP (Simple Mail Transfer Protocol)** | Sends email messages and attachments from clients to servers and between mail servers. |
| **POP (Post Office Protocol)** | Allows email clients to retrieve email and attachments from a remote mail server. |
| **IMAP (Internet Message Access Protocol)** | Allows email clients to retrieve and manage email directly on a remote server. |
| **DHCP (Dynamic Host Configuration Protocol)** | Automatically assigns IP addresses and network configuration information to devices. |
| **HTTP (Hypertext Transfer Protocol)** | Used by web browsers to request web pages and by web servers to deliver web content. |
| **FTP (File Transfer Protocol)** | Enables interactive file transfer between systems. |

These protocols work together to support everyday internet and network-based applications.
