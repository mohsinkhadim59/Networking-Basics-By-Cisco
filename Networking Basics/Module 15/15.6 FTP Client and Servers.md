## File Transfer Protocol (FTP)

- **FTP** is a common internet service used to **transfer files** between computers
- Allows users to **upload**, **download**, and **manage files** on a remote system

### FTP Client and Server
- A device running **FTP client software** connects to an **FTP server**
- The FTP server stores files and responds to client requests
- Clients can perform file management actions such as:
  - Uploading files
  - Downloading files
  - Deleting files
  - Renaming files

### Ports Used by FTP
- FTP uses **two TCP ports**:
  - **Port 21** – Control connection  
    - Used to start the FTP session and send commands aka `Command Port`
  - **Port 20** – Data connection  
    - Used to transfer actual file data

### FTP Operation Flow
1. Client initiates a connection to the FTP server on **TCP port 21**
2. Control session is established for commands
3. File data is transferred using **TCP port 20**

### FTP Software
- FTP client functionality is often:
  - Built into operating systems
  - Included in many web browsers
- **Stand-alone FTP clients** provide:
  - Graphical user interfaces (GUI)
  - Advanced file management features
