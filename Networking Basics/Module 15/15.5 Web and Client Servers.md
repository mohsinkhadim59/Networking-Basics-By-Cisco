## HTTP and HTML

### HTTP (Hypertext Transfer Protocol)
- Defines the rules for communication between a **web client** and a **web server**
- Used to **request** web pages from a server and **deliver** responses back to the client
- Operates after the destination IP address of the web server is known
- **Not secure by default** — data is sent in plain text and can be intercepted

### HTTPS (Secure HTTP)
- Uses HTTP over a **secure transport protocol (TLS/SSL)**
- Encrypts data to protect it from interception
- Secure HTTP requests are sent to **port 443**
- Uses `https://` instead of `http://` in the browser address bar

### HTML (Hypertext Markup Language)
- The **markup language** used to create and structure web pages
- Contains the content and formatting instructions that browsers display
- Sent from the web server to the client inside the HTTP/HTTPS response

### Web Page Request Process

1. The user enters a URL (e.g., `https://www.cisco.com`)
2. The client contacts a **DNS server** to resolve the domain name to an IP address
	 ![DNS Query](/Imagesn/133.png)
3. DNS returns the IP address associated with the domain name
4. The client establishes a connection to the web server  
	![HTTP Request](/Imagesn/134.png)   
   - HTTP → port 80  
   - HTTPS → port 443
5. The client sends an HTTP/HTTPS request to the web server
6. The web server responds with **HTML content**
	 ![HTML Content](/Imagesn/135.png)
7. The browser interprets the HTML and displays the web page
	 ![Web Page Display](/Imagesn/136.png)

### Interoperability
- Many different **web servers** and **web clients** exist
- The **HTTP protocol** and **HTML standards** allow devices and software from different manufacturers to work together seamlessly
