## Email Services

- Email is one of the most widely used **client/server applications** on the internet
- Email servers run software that allows them to:
  - Communicate with email clients
  - Exchange messages with other email servers

### Mail Servers and Clients
- Each mail server:
  - Receives and stores email for users
  - Maintains user mailboxes
- Users access email using an **email client**
- Many systems use **web-based email clients**, such as:
  - Microsoft 365
  - Yahoo Mail
  - Gmail
### Mailbox Identification
- Email addresses follow this format:
  - `user@company.domain`
### Email Protocols
- **SMTP** – Sends email between clients and servers and between servers
- **POP3** – Downloads email from the server to the client
- **IMAP4** – Accesses and manages email directly on the server

## Email Protocols

### Simple Mail Transfer Protocol (SMTP)
- Used by email clients to **send messages** to their local email server
- Email servers also use SMTP to send mail to **other email servers**
- Determines whether the destination mailbox is local or remote
- Uses **TCP port 25**
	-  Following are the steps that show us the **SMTP** in action:
		- The mail from the sender goes to the **Mail Server ISP A**
		![SMTP](/Imagesn/145.png)
		- It checks that if mail is intended for the local mailbox or the mailbox of another server. If it is intended for another server like in our case the mail will be sent to the other server like **ISP B**
		![SMTP](/Imagesn/146.png)
		- The mail is then received by the **ISP B** available to the **Recipient** when desired.
		![SMTP](/Imagesn/147.png)
### Post Office Protocol version 3 (POP3)
- Server **receives and stores** messages for users
- When the client connects, messages are **downloaded to the client**
- By default, messages are **removed from the server** after download
- Uses **TCP port 110**

### Internet Message Access Protocol (IMAP4)
- Server **stores messages** in user mailboxes
- Messages remain on the server unless **deleted by the user**
- Allows access to email from **multiple devices**
- Uses **TCP port 143**
- Multiple email server implementations exist across different network operating systems

## Text Messaging

- One of the most widely used communication methods today
- Built into many:
  - Online applications
  - Smartphone apps
  - Social media platforms
- Supports **real-time, two-way communication** (both users can send and receive simultaneously)

### Common Names
- Instant messages
- Direct messages
- Private messages
- Chat messages
![Text Messaging](/Imagesn/148.png)
### Characteristics
- Typically accessed via **web-based clients** on social media or collaboration platforms
- Usually limited to communication **within the same service**
- Supports more than text, including:
  - Documents
  - Images
  - Audio
  - Video

### Examples of Text Messaging Applications
- Cisco Webex Teams
- Microsoft Teams
- WhatsApp
- Facebook Messenger
- Available across multiple operating systems and devices
- Mobile versions are commonly provided

## Internet Phone Calls (VoIP)

- Internet telephony enables **voice calls over IP networks**
- Uses **Voice over IP (VoIP)** technology
- Converts analog voice into digital data
- Voice data is encapsulated into **IP packets** and transmitted over the network

### Requirements
- VoIP client software installed on the device
- Unique username for call identification
- Speakers and microphone (often a headset)

### How Calls Work
- Calls between users of the **same service** use the internet directly
- Calls to traditional phones require a **gateway to the PSTN**
- PSTN calls may involve additional charges
- Protocols and ports vary depending on the application
![VoIP](/Imagesn/149.png)
### Typical VoIP Architecture
- Voice client (computer or IP phone)
- Internet connection
- Voice server (call manager)
- Other voice clients or IP phones connected through the internet
