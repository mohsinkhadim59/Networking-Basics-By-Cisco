## The IPv4 Address 
- An **IPv4 address** is a logical network address that uniquely identifies a device (host) on a network.
- To communicate:
  - A device must have a **unique IPv4 address within the local network (LAN)** for local communication.
  - It must also have a **unique IPv4 address globally** if it needs to communicate across the internet.

### Where IPv4 Addresses Are Used
- IPv4 addresses are assigned to **network interfaces**, usually through a **Network Interface Card (NIC)**.
- Examples of devices that have NICs and need IPv4 addresses:
  - Computers (desktops, laptops)
  - Servers
  - Network printers
  - IP phones
  - Routers (each interface on a router can have its own IPv4 address)

- Some servers may have **multiple NICs**, so they can have multiple IPv4 addresses.

### How IPv4 Works in Communication
- Every packet sent over a network includes:
  - A **source IPv4 address** (where it came from)
  - A **destination IPv4 address** (where it’s going)

- Networking devices (like routers) use this information to:
  - Forward packets to the correct destination
  - Make sure responses return to the original sender

### Real-Life Examples
- **Browsing a website:**
  When you visit www.cisco.com, your device sends a packet with your IPv4 address as the source. Cisco servers use that address to send the webpage back to you.

## Summary: Octets and Dotted-Decimal Notation 

### IPv4 Address Length
- An **IPv4 address is 32 bits long**.
- Example in binary: 11010001101001011100100000000001

### Why Octets Are Used
- A 32-bit number is hard to read, so it is divided into **four groups of 8 bits**.
- Each group of 8 bits is called an **octet**.
- Same example broken into octets: 11010001.10100101.11001000.00000001
### Dotted-Decimal Notation
- Binary is still difficult for humans to read, so each octet is converted into a **decimal number**.
- The final, user-friendly IPv4 format becomes: 209.165.200.1
### Why This Matters
- Humans use dotted-decimal notation because it’s easier to read and configure on devices.
- Behind the scenes, computers still use the 32-bit binary version to process the address.

### Real-Life Examples
- **Typing an IP address into a browser:**  
When you enter `192.168.1.1` to access your home router settings, you’re using dotted-decimal notation.  
Behind the scenes, the router sees it as a 32-bit binary value.

- **Configuring a printer or server:**  
When an IT technician sets a printer’s IP to `10.0.0.25`, they are entering a simple dotted-decimal version instead of a long binary string.

---

>[!tip]
> You don’t need to know how to convert between binary and decimal yet just understand why the conversion is used.
