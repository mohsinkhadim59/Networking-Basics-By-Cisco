# DHCP Address Assignment in a Small Network

There are two ways for a device to obtain an IPv4 address:
- Manually (Static Configuration)
- Automatically (DHCP – Dynamic Host Configuration Protocol)

In this network  given below as an `Example`, all PCs obtain their IP addresses automatically from a DHCP-enabled router.

---

## Network Topology
```bash
                       Internet
                          |
                          |
                  -----------------
                  |   DHCP Router  |
                  |  (172.16.0.1)  |  ← Default Gateway
                  -----------------
                     |      |      |
        --------------      |      --------------
        |                   |                   |
        |                   |                   |
   -----------         -----------         -----------
   |   PC0   |         |   PC1   |         |   PC2   |
   -----------         -----------         -----------
   DHCP: ON            DHCP: ON            DHCP: ON
   IP: 172.16.0.100    IP: 172.16.0.101    IP: 172.16.0.102
   GW: 172.16.0.1      GW: 172.16.0.1      GW: 172.16.0.1

```
        
---

## Router DHCP Configuration

The router has DHCP enabled by default.  
It already has an IP address assigned to its LAN interface, which becomes the default gateway for all PCs.

A range of IP addresses is reserved to be handed out dynamically to hosts.

>DHCP Pool Start Address:172.16.0.100

Each device that requests an IP address receives the next available address in the sequence.

---

## DHCP Address Assignment Process
```bash
PC0  ----DHCP Request---->  Router  
Router ----Assigns 172.16.0.100----> PC0  

PC1  ----DHCP Request---->  Router  
Router ----Assigns 172.16.0.101----> PC1  

PC2  ----DHCP Request---->  Router  
Router ----Assigns 172.16.0.102----> PC2  

```

Each PC automatically receives:
- IP Address
- Subnet Mask
- Default Gateway (172.16.0.1)

---

## Changing from Static to DHCP

Each PC initially has a statically configured IP address.  
When the configuration is changed to DHCP:
- The PC immediately sends a DHCP request
- The router responds with an available IP address
- The PC automatically applies the new settings
```bash
The first PC gets:
172.16.0.100

The next PCs get:
172.16.0.101  
172.16.0.102  

No two devices receive the same IP address.

```

---

## Network Connectivity Testing

After all PCs receive their IP addresses, connectivity is tested using ping.
```bash
PC0 (172.16.0.100)
   |
   |---- ping ----> PC1 (172.16.0.101) ✅ Reply Received
   |
   |---- ping ----> PC2 (172.16.0.102) ✅ Reply Received

```

Successful ping replies confirm that:
- All devices received valid IP addresses
- The default gateway is working
- The local network is connected properly

---

>[!notes]
>
The DHCP configuration on the router fully determines:
>- Which IP addresses are assigned
>- The order in which they are assigned
>- The default gateway used by all hosts

## How DHCP Works

- IPv4 addresses can be assigned in two ways:
  - **Static** – Manually configured by a person.
  - **Dynamic** – Automatically assigned by a DHCP server.
- **DHCP** stands for **Dynamic Host Configuration Protocol**.
- It is the protocol used by a device to automatically obtain its IP addressing information.

---
## DHCP DORA Process 

The DHCP process follows four main steps known as **DORA**:

---

### 1. Discover
**Client → Broadcast → Network**

- The client does not have an IP address.
- It sends a **DHCP Discover** message as a **broadcast**.
- Purpose: *Find any available DHCP servers.*
- Includes the client’s **MAC address**.

---

### 2. Offer
**DHCP Server → Client**

- A DHCP server responds with a **DHCP Offer**.
- The offer contains:
  - Proposed **IPv4 address**
  - **Subnet mask**
  - **Default gateway**
  - Other optional configuration details
- This is an **available address** the client may use.

---

### 3. Request
**Client → DHCP Server**

- The client sends a **DHCP Request** message.
- This message:
  - Accepts the offered IP address
  - Tells all DHCP servers which offer it selected

---

### 4. Acknowledgement (ACK)
**DHCP Server → Client**

- The DHCP server sends a **DHCP Acknowledgement (ACK)**.
- This confirms:
  - The IP address is **officially assigned**
  - The lease is recorded using the client’s **MAC address**
- The client applies the settings and can now communicate on the network.

---

## DORA Flow Summary



*Client → Discover → Network*  
*Server → Offer → Client*  
*Client → Request → Server*  
*Server → ACK → Client*

---

>[!tip] Key Notes
>
>- DHCP uses **broadcast and unicast** transmissions.
>- The IP address is **leased**, not permanently assigned.
>- The process happens automatically when a device joins a network.

**Packet Tracer - Configure DHCP on a Wireless Router**

## Objectives

- Connect 3 PCs to a wireless router
- Change the DHCP setting to a specific network range
- Configure the clients to obtain their address via DHCP

## Background / Scenario

A home user wants to use a wireless router to connect 3 PCs. All 3 PCs should obtain their address automatically from the wireless router.

## Instructions

## Part 1: Set up the network topology

1. Add three generic PCs.
2. Connect each PC to an Ethernet port to the wireless router using straight-through cables.

## Part 2: Observe the default DHCP settings

1. After the amber lights have turned green, click **PC0**. Click the **Desktop** tab. Select **IP Configuration**. Select **DHCP** to receive an IP address from **DHCP Enabled Router**.

>Record the IP address of the default gateway:
>Answer Area:192.168.0.100

2. Close the **IP Configuration** window.
3. Open a Web Browser.
4. Enter the IP address of the default gateway recorded earlier into the URL field. When prompted, enter the username **admin** and password **admin**.
5. Scroll through the Basic Setup page to view default settings, including the default IP address of the wireless router.
6. Notice that DHCP is enabled, the starting address of the DHCP range and the range of addresses available to clients.

## Part 3: Change the default IP address of the wireless router.

1. Within the Router IP Settings section, change the IP address to: **192.168.5.1**.
2. Scroll to the bottom of the page and click **Save Settings.**
3. If it is done correctly, the web page will display an error message. Close the web browser.
4. Click **IP Configuration** to renew the assigned IP address. Click **Static**. Click **DHCP** to receive new IP address information from the wireless router.
5. Open the web browser, enter the IP address **192.168.5.1** in the URL field. When prompted, enter the username **admin** and password **admin**.

## Part 4: Change the default DHCP range of addresses.

1. Notice the DHCP Server Start IP Address is updated to the same network as the Router IP.
2. Change the Starting IP Address from 192.168.5.100 to **192.168.5.126.**
3. Change the Maximum Number of Users to **75**.
4. Scroll to the bottom of the page and click **Save Settings**. Close the web browser.
5. Click **IP Configuration** to renew the assigned IP address. Click **Static**. Click **DHCP** to receive new IP address information from the wireless router.
6. Select **Command Prompt**. Enter **ipconfig**.

>Record the IP address for PC0:
  Answer Area:192.168.5.26

## Part 5: Enable DHCP on the other PCs.

1. Click **PC1**.
2. Select **Desktop** tab.
3. Select IP Configuration.
4. Click **DHCP**.

>Record the IP address for PC1:
>Answer Area:192.168.5.27

5. Close the configuration window.
6. Enable DHCP on **PC2** following the steps for PC1.

## Part 6: Verify connectivity

1. Click **PC2** and select the **Desktop** tab.
2. Select Command Prompt.
3. Enter **ipconfig** at the prompt to view the IP configuration.
4. At the prompt, enter **ping 192.168.5.1** to ping the wireless router.
5. At the prompt, enter **ping 192.168.5.127** to ping PC1.
6. The pings to all devices should be successful.
