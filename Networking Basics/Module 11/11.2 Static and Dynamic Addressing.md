## Static IPv4 Address Assignment

- IPv4 addresses can be assigned **statically** or **dynamically**.
- With **static assignment**, the network administrator manually configures the network settings for each host.

### Required Configuration for Static Assignment
- **IP address** – Identifies the host on the network.
- **Subnet mask** – Identifies the network the host is connected to.
- **Default gateway** – Identifies the device used to reach remote networks or the internet.
![Static](/Imagesn/98.png)
### Advantages of Static Addressing
- Useful for:
  - Printers
  - Servers
  - Network devices that must always be reachable at the same address
- Provides increased control of network resources.
- Addresses do not change.

### Disadvantages of Static Addressing
- Time-consuming to configure on each device.
- Hosts perform only basic error checking.
- Configuration errors are more likely.
- Requires maintaining an accurate record of assigned addresses.
- Addresses are permanent and normally not reused.

## Dynamic IPv4 Address Assignment

- On many networks, users and devices change frequently.
- Instead of manual configuration, IPv4 addresses can be assigned automatically using **Dynamic Host Configuration Protocol (DHCP)**.
![Static](/Imagesn/99.png)
### Information Provided by DHCP
- IPv4 address
- Subnet mask
- Default gateway
- Other network configuration details

### Benefits of DHCP
- Reduces workload for network administrators.
- Virtually eliminates manual entry errors.
- Addresses are **leased**, not permanently assigned.
- When a host leaves the network, the address is returned to the pool for reuse.
- Especially useful for networks with mobile users.

## DHCP Servers

- A **DHCP server** is any device running DHCP service software.
- DHCP allows devices to automatically receive IPv4 configuration when they connect to a network.
- ![Static](/Imagesn/100.png)

### Common DHCP Server Implementations
- **Medium to large networks:**
  - Dedicated PC-based servers typically provide DHCP services.
- **Home networks:**
  - The DHCP server may be located at the ISP.
  - Internal hosts receive their configuration directly through the ISP.
- **Wireless routers:**
  - Act as a **DHCP client** to receive a public IPv4 address from the ISP.
  - Act as a **DHCP server** to distribute private IPv4 addresses to internal hosts.
- **Other devices:**
  - Some dedicated routers can also function as DHCP servers, though this is less common.
