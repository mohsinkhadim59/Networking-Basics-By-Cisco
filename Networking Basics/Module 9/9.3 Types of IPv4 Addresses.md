## Public and Private IPv4 Addresses 

IPv4 addresses come in different types depending on their use.  
Some are meant for communication on the public internet, while others are reserved only for internal networks.

### **Public IPv4 Addresses**
- Globally unique and routable on the internet.
- Assigned by ISPs or regional internet registries.
- Used for devices/servers that must be reachable from anywhere.

### **Private IPv4 Addresses**
- Introduced in the mid-1990s due to IPv4 exhaustion.
- Not routable on the public internet.
- Free to use inside any internal network (LANs, companies, homes).
- Defined in **RFC 1918**.

### **RFC 1918 Private Ranges**
| Network | Private Address Range |
|--------|------------------------|
| **10.0.0.0/8** | 10.0.0.0 – 10.255.255.255 |
| **172.16.0.0/12** | 172.16.0.0 – 172.31.255.255 |
| **192.168.0.0/16** | 192.168.0.0 – 192.168.255.255 |

### **Key Points**
- Private addresses are **not unique** globally.
- They allow organizations to have many internal hosts without using public IPs.
- The long-term solution to IPv4 shortage is **IPv6**.

# Public vs Private IPv4 Addresses

When we use IPv4 addresses, they are not all the same.  
Some can go **onto the internet**, and some can **only be used inside local networks** like homes, schools, or companies.


---

#  1. Public IPv4 Addresses

A **public IP address** is:

- **Globally unique** → no two devices on the entire internet share it
    
- **Assigned by ISPs**
    
- **Routable on the internet** → meaning the internet routers know how to reach it
    

Example:  
A website server (like google.com) must use a public IP so anyone in the world can connect.

Think of a **public IP like your home’s street address**.  
Anyone can send you mail.

---

#  2. Private IPv4 Addresses

In the mid-1990s, the internet started running out of IPv4 addresses.  
So they created **private addresses** that:

- Are **NOT** routable on the public internet
    
- **Can be reused** in every home, school, company
    
- Are **free to use** — no ISP needed
    
- Are used only **inside local networks**
    

These private ranges are defined by **RFC 1918**.

### The 3 private ranges:

| Range              | Meaning                                     |
| ------------------ | ------------------------------------------- |
| **10.0.0.0/8**     | Huge networks (big companies, data centers) |
| **172.16.0.0/12**  | Medium-size networks                        |
| **192.168.0.0/16** | Most common in home routers (192.168.0.x)   |

>[!Example] - Simple Example  
> - Your home Wi-Fi probably uses **192.168.1.1** as the router address.
> - Private IPs are like **your room number inside a building**.  
> - People on the street can’t see your room number — only inside the building.

# 🚫 Why can’t private IPs go on the internet?

Routers on the internet are programmed to **drop RFC 1918 addresses**.  
Because these are **internal only**.

So if a computer with address 192.168.1.5 directly tries to go online, the internet routers would reject it.

This is why we need **NAT (Network Address Translation)**, but that's another topic.

---

# 🍀 3. Why private addresses were created

Because IPv4 has only **4.29 billion** total addresses, and the world ran out.

Using private IPs:

- Every home can reuse 192.168.x.x
    
- Every company can reuse 10.x.x.x
    
- Everyone can reuse the same private ranges without conflict
    

This allowed the internet to keep working until IPv6 came along.
